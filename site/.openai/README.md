# Tamil Nadu Industrial Policy Outcomes Observatory

An evidence-led public dashboard covering 33 Tamil Nadu industrial policies and
41 headline outcome commitments. It distinguishes outcomes that can be tested
from public data from those that require unpublished administrative records.

## Evidence model

- **Independent direct:** the public source measures the target closely enough
  to score it.
- **Independent partial:** the source measures a material part of the target,
  but not the entire commitment.
- **Official proxy:** a relevant outcome exists, but it is not the promised
  construct.
- **Administrative data required:** the commitment cannot be independently
  verified without records such as commissioned projects, audited investment,
  payroll, land allotment, or scheme beneficiaries.

The observatory reports descriptive outcomes. It does not claim a policy caused
an observed change. ASI monetary series are current rupees; real manufacturing
growth uses Tamil Nadu DES constant-price GSVA.

## Data

`public/data/observatory.json` is generated by the parent repository's
`scripts/build_observatory_data.py`. It combines:

- the policy corpus and hand-audited commitment ledger;
- disclosure-safe, survey-weighted ASI aggregates for 2008-09 to 2023-24;
- Tamil Nadu DES manufacturing GSVA at current and constant prices;
- MNRE state solar capacity at the 2019 policy deadline; and
- official ASI table benchmarks used to validate the harmonized pipeline.

Raw ASI microdata are restricted and are deliberately excluded from this Git
repository. Only reproducible code and disclosure-safe aggregates may be
published.

## Run locally

Requires Node.js `>=22.13.0`.

```bash
npm install
npm run dev
npm test
```

`npm test` performs a production build, checks the rendered shell, reconciles
all policy and target counts, and verifies ASI coverage and benchmark metadata.

## Deploy a Fork

`site/.openai/hosting.json` is deliberately local-only because it contains the
deployment binding for the owner's private site. Copy
`site/.openai/hosting.example.json` to `site/.openai/hosting.json` before
creating a new deployment binding for a fork.
